Установка с компьютера

Отсканируйте смартфоном QR-код для скачивания приложения

Инструкция по установке приложения

  • Скачайте приложение: со смартфона — по кнопке «Скачать приложение», с компьютера — отсканируйте смартфоном QR-код
  • Откройте скачанный файл chz-scanner.apk
  • Если телефон спросит — разрешите установку из этого источника
  • Нажмите «Установить» и откройте приложение
  • Введите номер телефона в формате 79251240615
  • Введите код активации (4 цифры) — запросите его по телефону у представителя компании (логиста)
  • Готово — приложение настроится автоматически и можно начинать сканирование
Нет кода активации? Код выдаёт логист компании — один код действует для одной установки приложения.

Возможности

  • Сканирование GS1 DataMatrix и штрихкодов упаковок
  • Контроль приёмки по плану УПД: план/факт по каждой позиции
  • Замена нечитаемого штрихкода упаковки кодом единицы товара
  • Фотофиксация каждого отсканированного кода
  • Автоматическая отправка результатов в 1С и специалисту ЧЗ
  • Справочники SKU и УПД обновляются автоматически
  • Автообновление приложения до актуальной версии
