Сканер «Честный Знак»

Приёмка маркированного товара по УПД
Версия 1.1 · 05.08.2026 · Android 8.0+
⬇ Скачать приложение (APK)
~19 МБ · установка вне Google Play

Возможности

  • Сканирование GS1 DataMatrix и штрихкодов упаковок
  • Контроль приёмки по плану УПД: план/факт по каждой позиции
  • Замена нечитаемого штрихкода упаковки кодом единицы товара
  • Фотофиксация каждого отсканированного кода
  • Автоматическая отправка результатов в 1С и специалисту ЧЗ
  • Справочники SKU и УПД обновляются автоматически

Установка

  • Нажмите «Скачать приложение» выше
  • Откройте скачанный файл chz-scanner.apk
  • Разрешите установку из этого источника, если телефон спросит
  • Нажмите «Установить» и откройте приложение

Подключение

  • Настройки почты выдаёт администратор
  • По вопросам подключения обратитесь к администратору приложения
